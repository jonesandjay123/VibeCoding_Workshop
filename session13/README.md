# Session 13：先找出她需要的幫助，再一起解決一個問題

> **日期：** 2026-10-09。上課時間與時區以雙方約定為準。
> **時長：** 120 分鐘，包含 5 分鐘休息和 5 分鐘機動時間。
> **本課起點：** 妹妹說 Codex 又能用了，也用它做了數據可視化作業；但她還不清楚 Jupyter 和 Pandas。

## 今天先不決定要教完哪些內容

**Session 12 曾經規劃，但沒有實際上課。** 因此，不能假定她已經學過選圖、裝好 Python，或完成任何前置練習。

明天先請她打開最近正在做的作業或教材，聽她說現在想完成什麼。導師再根據她的說明，選出一個這兩小時內可以幫上忙的問題。

`student-workbook.ipynb` 是備用素材庫，不是必須從第 0 格一路教到最後的課程。需要說明「篩選」時，只取篩選例子；需要理解 Jupyter 時，先做小型狀態實驗。她已經會的部分就跳過。

## 開場 15–20 分鐘：先問，再選題

一次只問一個問題，給她時間打開資料、指給你看。

1. 「妳最近正在做哪份作業，或學到哪一頁？可以打開給我看嗎？」
2. 「妳今天最想完成或弄懂的是什麼？」
3. 「目前哪一步已經做得出來？可以示範到那一步嗎？」
4. 「接下來卡在哪裡？是不知道題目要什麼、程式不能跑，還是結果出來了但不知道對不對？」

最後由導師確認：「所以今天先一起解決＿＿，完成時我們要能看到／說明＿＿，這樣對嗎？」

不要把開場變成測驗。暫時說不出來也沒關係，請她示範一步就好。真實資料不能分享時，請她說明欄位與問題，改用本課合成資料演示同一個概念。

## 120 分鐘的彈性安排

時間框架固定，裡面的題目依她的需要選擇。

| 經過時間 | 做什麼 | 到這一段結束時，確認什麼 |
| :--- | :--- | :--- |
| 00–20 | 看最近的作業與教材，了解目標和卡點 | 雙方同意今天只處理一個主要問題；若第 15 分鐘已確認，就用餘下時間打開所需檔案 |
| 20–30 | 確認最小執行環境，選擇下面的一條支線 | 能執行一小段必要代碼，或已切換到導師示範的備援方式 |
| 30–55 | 一起處理選定問題的第一步 | 她能說明這一步做了什麼，並看到一個中間結果 |
| 55–60 | 休息 | 暫時離開螢幕 |
| 60–85 | 繼續同一個問題，檢查結果 | 至少做一個具體驗證，例如抽查原始行、手算或核對圖表 |
| 85–100 | 請她自己操作一小步，或解釋一個改動 | 知道改了什麼，以及結果為什麼跟著改變 |
| 100–105 | 機動時間 | 處理短暫連線、路徑或字型問題；沒有延誤就再檢查結果 |
| 105–115 | 保存本次成果，重新執行選定的分析 | 能重現剛才的結果；若還不能，記下具體卡點，不假裝完成 |
| 115–120 | 用她自己的話收尾 | 說出今天解決了什麼、如何知道它合理，以及下一步需要什麼 |

### 根據卡點選一條支線

- **A：程式怎麼執行還不清楚。** 用 Jupyter 小實驗解釋 cell 和 kernel。之後回到她原本的程式，找出執行順序或缺少的前置步驟。不必接著教全部 Pandas。
- **B：看到表格，但不知道如何得到想要的數字。** 先弄清楚「一行代表什麼」。按需要挑讀表、篩選或分組例子，得到一張能解釋的結果表。不必為了教材進度畫圖。
- **C：AI 已經畫出圖，但不知道是否回答題目。** 從圖追溯到使用的資料和中間表，核對年份、單位與加總方式。需要時才補一段 Pandas 說明。

三條支線共用同一份時間表，不是各上一次。若遇到第二個問題，先記下來；除非它阻礙目前的目標，否則不要中途擴課。

## 怎麼教，才不會只是陪她跑代碼

先讓她把問題說清楚。只在關鍵轉折請她做一個簡單預測，例如「如果只留 2025 年，應該會剩哪些店？」不需要每一行都猜。

AI 可以解釋代碼、提供小段範例或協助除錯。學生仍要看得懂與問題有關的那幾行，能說明資料怎麼被改動。**程式沒有報錯，不代表問題答對了。** 例如題目要 2025 年的利潤，AI 卻算五年總和，程式仍可能正常畫出一張漂亮的圖。

看懂必要代碼有幫助，但今天不把 API 名稱、Series 與 DataFrame 的細部差異或 `assert` 語法當成必考內容。只有她問到、或它真的阻礙目前問題時，才展開說明。

## 課前只確認必要條件

- [ ] 導師先看 [`live-runbook.md`](./live-runbook.md)，準備提問與備援，不先替學生選好問題。
- [ ] 準備 [`student-workbook.ipynb`](./student-workbook.ipynb) 和 `data/` 子目錄，作為可挑選的例子。
- [ ] 只做 kernel 狀態實驗時，先執行 `print(1 + 1)`，看到 2 即可，不需要 pandas 或 matplotlib。要使用 Pandas 素材時，再執行 workbook 的環境格，確認 Python 路徑及套件；不要假定終端機與 notebook 使用同一個 Python。
- [ ] 已能執行就不重裝。若缺套件，先查缺哪個、裝到哪個環境；不要把新建 `.venv` 誤認為教材本身需要修改。
- [ ] AI 工具以學生當天實際能用的為準。Codex 可優先使用；其他已確認可用的工具或本地示範都可以，不假定她上過任何工具設定課。

環境排查最多借用 5 分鐘機動時間。仍無法執行，就由導師使用已確認能跑的環境示範，讓她口述下一步與檢查結果；學生端的獨立執行記為待補。

## 素材庫如何挑選

| 現在需要的幫助 | 打開哪裡 |
| :--- | :--- |
| 聽不懂 kernel 或變數的行為 | Runbook 的「支線 A」，或學生小抄第一部分 |
| 看不懂 `shape`、`head`、欄位名稱 | Workbook 模組 0、1 |
| 想確認型別、缺值、重複 | Workbook 模組 2；三份報告分開看 |
| 想只保留符合條件的行 | Workbook 模組 4；先執行模組 0、1 |
| 想把多行資料合成每店一個總數 | Workbook 模組 5；先執行模組 0、1 |
| 已有正確的統計表，想畫圖 | Workbook 模組 6；先確認它是否符合目前問題 |
| 想練一個小改動 | Workbook 模組 7 或 8，依需求選一題即可 |

Workbook 每一段都寫明前置步驟。可以跳過不需要的主題，但不能跳過程式所需的變數定義。最後重跑的是**本次選定分析及其前置步驟**，不是要求把整個素材庫教完。

## 用語音協助現場教學

導師可以一邊看學生示範，一邊透過語音請助手協助解釋。助手不會自動看到 Zoom、學生螢幕或最新執行結果；請口述目前畫面，或提供已去除敏感資訊的截圖。

臨時需要改教材時，先請助手提出一個小改動，讓課程繼續。修改、測試、commit 和 push 都需要時間，不能假定掛著電話就會即時同步到本機。取得「已推送」的確認後，再依 Runbook 的安全更新步驟取得新版。

## 資料與隱私

本 repo 是公開的。本課的 CSV 是合成資料：一行是一家門店一年，金額單位設定為萬元人民幣。`category` 只表示當年主力品類，不能用來算各品類真正賺了多少錢。詳見 [`data/README.md`](./data/README.md)。

學生的真實作業、成績、同學資料、私人截圖及 notebook 舊輸出，不會因為拿來上課就自動獲准公開。先確認使用方式和學校的 AI 規定；只分享最少必要內容，不將真實資料或本機環境檔案加入這個 repo。
