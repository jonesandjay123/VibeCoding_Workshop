# Session 13：先找出她需要的帮助，再一起解决一个问题

> **日期：** 2026-10-09。上课时间与时区以双方约定为准。
> **时长：** 120 分钟，包含 5 分钟休息和 5 分钟机动时间。
> **本课起点：** 妹妹说 Codex 又能用了，也用它做了数据可视化作业；但她还不清楚 Jupyter 和 Pandas。

## 今天先不决定要教完哪些内容

**Session 12 曾经规划，但没有实际上课。** 因此，不能假定她已经学过选图、装好 Python，或完成任何前置练习。

明天先请她打开最近正在做的作业或教材，听她说现在想完成什么。导师再根据她的说明，选出一个这两小时内可以帮上忙的问题。

`student-workbook.ipynb` 是备用素材库，不是必须从第 0 格一路教到最后的课程。需要说明「筛选」时，只取筛选例子；需要理解 Jupyter 时，先做小型状态实验。她已经会的部分就跳过。

## 开场 15–20 分钟：先问，再选题

一次只问一个问题，给她时间打开数据、指给你看。

1. 「你最近正在做哪份作业，或学到哪一页？可以打开给我看吗？」
2. 「你今天最想完成或弄懂的是什么？」
3. 「目前哪一步已经做得出来？可以示范到那一步吗？」
4. 「接下来卡在哪里？是不知道题目要什么、程序不能跑，还是结果出来了但不知道对不对？」

最后由导师确认：「所以今天先一起解决＿＿，完成时我们要能看到／说明＿＿，这样对吗？」

不要把开场变成测验。暂时说不出来也没关系，请她示范一步就好。真实数据不能分享时，请她说明字段与问题，改用本课合成数据演示同一个概念。

## 120 分钟的弹性安排

时间框架固定，里面的题目依她的需要选择。

| 经过时间 | 做什么 | 到这一段结束时，确认什么 |
| :--- | :--- | :--- |
| 00–20 | 看最近的作业与教材，了解目标和卡点 | 双方同意今天只处理一个主要问题；若第 15 分钟已确认，就用余下时间打开所需文件 |
| 20–30 | 确认最小执行环境，选择下面的一条支线 | 能执行一小段必要代码，或已切换到导师示范的备援方式 |
| 30–55 | 一起处理选定问题的第一步 | 她能说明这一步做了什么，并看到一个中间结果 |
| 55–60 | 休息 | 暂时离开屏幕 |
| 60–85 | 继续同一个问题，检查结果 | 至少做一个具体验证，例如抽查原始行、手算或核对图表 |
| 85–100 | 请她自己操作一小步，或解释一个改动 | 知道改了什么，以及结果为什么跟著改变 |
| 100–105 | 机动时间 | 处理短暂连线、路径或字体问题；没有延误就再检查结果 |
| 105–115 | 保存本次成果，重新执行选定的分析 | 能重现刚才的结果；若还不能，记下具体卡点，不假装完成 |
| 115–120 | 用她自己的话收尾 | 说出今天解决了什么、如何知道它合理，以及下一步需要什么 |

### 根据卡点选一条支线

- **A：程序怎么执行还不清楚。** 用 Jupyter 小实验解释 cell 和 kernel。之后回到她原本的程序，找出执行顺序或缺少的前置步骤。不必接著教全部 Pandas。
- **B：看到表格，但不知道如何得到想要的数字。** 先弄清楚「一行代表什么」。按需要挑读表、筛选或分组例子，得到一张能解释的结果表。不必为了教材进度画图。
- **C：AI 已经画出图，但不知道是否回答题目。** 从图追溯到使用的数据和中间表，核对年份、单位与加总方式。需要时才补一段 Pandas 说明。

三条支线共用同一份时间表，不是各上一次。若遇到第二个问题，先记下来；除非它阻碍目前的目标，否则不要中途扩课。

## 怎么教，才不会只是陪她跑代码

先让她把问题说清楚。只在关键转折请她做一个简单预测，例如「如果只留 2025 年，应该会剩哪些店？」不需要每一行都猜。

AI 可以解释代码、提供小段范例或协助除错。学生仍要看得懂与问题有关的那几行，能说明数据怎么被改动。**程序没有报错，不代表问题答对了。** 例如题目要 2025 年的利润，AI 却算五年总和，程序仍可能正常画出一张漂亮的图。

看懂必要代码有帮助，但今天不把 API 名称、Series 与 DataFrame 的细部差异或 `assert` 语法当成必考内容。只有她问到、或它真的阻碍目前问题时，才展开说明。

## 课前只确认必要条件

- [ ] 导师先看 [`live-runbook.md`](./live-runbook.md)，准备提问与备援，不先替学生选好问题。
- [ ] 准备 [`student-workbook.ipynb`](./student-workbook.ipynb) 和 `data/` 子目录，作为可挑选的例子。
- [ ] 只做 kernel 状态实验时，先执行 `print(1 + 1)`，看到 2 即可，不需要 pandas 或 matplotlib。要使用 Pandas 素材时，再执行 workbook 的环境格，确认 Python 路径及套件；不要假定终端机与 notebook 使用同一个 Python。
- [ ] 已能执行就不重装。若缺套件，先查缺哪个、装到哪个环境；不要把新建 `.venv` 误认为教材本身需要修改。
- [ ] AI 工具以学生当天实际能用的为准。Codex 可优先使用；其他已确认可用的工具或本地示范都可以，不假定她上过任何工具设定课。

环境排查最多借用 5 分钟机动时间。仍无法执行，就由导师使用已确认能跑的环境示范，让她口述下一步与检查结果；学生端的独立执行记为待补。

## 素材库如何挑选

| 现在需要的帮助 | 打开哪里 |
| :--- | :--- |
| 听不懂 kernel 或变量的行为 | Runbook 的「支线 A」，或学生小抄第一部分 |
| 看不懂 `shape`、`head`、字段名称 | Workbook 模块 0、1 |
| 想确认类型、缺值、重复 | Workbook 模块 2；三份报告分开看 |
| 想只保留符合条件的行 | Workbook 模块 4；先执行模块 0、1 |
| 想把多行数据合成每店一个总数 | Workbook 模块 5；先执行模块 0、1 |
| 已有正确的统计表，想画图 | Workbook 模块 6；先确认它是否符合目前问题 |
| 想练一个小改动 | Workbook 模块 7 或 8，依需求选一题即可 |

Workbook 每一段都写明前置步骤。可以跳过不需要的主题，但不能跳过程序所需的变量定义。最后重跑的是**本次选定分析及其前置步骤**，不是要求把整个素材库教完。

## 用语音协助现场教学

导师可以一边看学生示范，一边透过语音请助手协助解释。助手不会自动看到 Zoom、学生屏幕或最新执行结果；请口述目前画面，或提供已去除敏感资讯的截图。

临时需要改教材时，先请助手提出一个小改动，让课程继续。修改、测试、commit 和 push 都需要时间，不能假定挂著电话就会即时同步到本机。取得「已推送」的确认后，再依 Runbook 的安全更新步骤取得新版。

## 数据与隐私

本 repo 是公开的。本课的 CSV 是合成数据：一行是一家门店一年，金额单位设定为万元人民币。`category` 只表示当年主力品类，不能用来算各品类真正赚了多少钱。详见 [`data/README.md`](./data/README.md)。

学生的真实作业、成绩、同学数据、私人截图及 notebook 旧输出，不会因为拿来上课就自动获准公开。先确认使用方式和学校的 AI 规定；只分享最少必要内容，不将真实数据或本机环境文件加入这个 repo。
