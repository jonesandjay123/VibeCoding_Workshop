## Jupyter：文件、格子、記憶體

| 概念 | 一句話 | 日文 |
| :--- | :--- | :--- |
| Notebook | `.ipynb` 文件，保存代碼、說明與輸出；不保存活著的變數 | ノートブック |
| Cell | 一格代碼或文字；代碼格 Shift+Enter 送去執行 | セル |
| Kernel | 執行 Python、保留當前變數的程序 | カーネル |

- 改 cell 不等於已執行；下方可能仍顯示舊結果。
- 刪 cell 不會刪掉 kernel 裡的變數。
- **Restart** 清空 kernel。若只跑 `print(x)`，尚未重新定義 x，就會 `NameError`。
- **Restart＋Run All** 清空後按文件順序全跑；若上面有 `x = 10`，後面的 `print(x)` 就是 10。
- `[*]` 通常是忙碌；`[3]` 是執行計數，不是第 3 行，也不保證成功或輸出仍有效。空白可能尚未執行或已清除。

懷疑舊狀態時，**先保存，再重啟並全跑**。若是缺檔、缺套件或代碼錯誤，要讀報錯、修原因；重啟不是萬用修復。

## Pandas：用代碼操作表格

DataFrame 像一張 Excel 工作表，但它是 Python 的二維資料結構。每行是一筆記錄，每欄有名稱與型別；index 是行標籤，不一定連號或唯一。Series 是一維資料。

本課一行＝一家門店一年；20 行×5 欄，金額單位都是萬元（人民幣，合成練習）。`category` 只標主力品類，不可當成品類明細算貢獻。

| 動作 | 中文需求 | 關鍵代碼 |
| :--- | :--- | :--- |
| 讀 | 讀 CSV | `pd.read_csv(csv_path)` |
| 看 | 看形狀、前幾行、缺值 | `df.shape`、`df.head()`、`df.isna().sum()` |
| 選 | 只取利潤欄 | `df['profit']` 是 Series；`df[['profit']]` 是 DataFrame |
| 篩 | 只保留利潤大於 20 的行 | `filtered = df[df['profit'] > 20]` |
| 分組 | 各店五年利潤總和 | `totals = df.groupby('store')['profit'].sum()` |
| 畫 | 把已核對的總和畫成比較圖 | `totals.plot(kind='bar')` |

新結果用新名字，保留原始 `df`，避免前面的篩選偷偷影響後面的總和。

**分清三件事：**
- 篩行：留下哪些原始記錄？例如只取 2025 年。
- 分組：哪些記錄算在一起？用總和、平均還是個數？例如五年總和變成 4 組。
- 畫圖：把哪張統計表呈現出來？比較用條形圖；時間趨勢保留年份，用折線圖。`sort_index()` 可把年份由小到大排列，不改數值。

## 驗證清單

1. 一行代表什麼？欄位、型別、單位對嗎？`head()` 只顯示前幾行，不能證明全表沒有缺值或重複。
2. 篩選後幾行？手算 A 的 18＋22＋25＋30＋35＝130，再抽查另一店；分組總和要等於原表總和。
3. 分組欄位是否回答題目？`store` 的五年總數無法直接畫逐年趨勢。
4. 圖的年份、單位、標籤是否與表一致？存好後打開 PNG 看一遍。
5. 保存 notebook，乾淨重啟後從上到下再跑，確認不是舊輸出。

## 卡住時怎麼問 AI
