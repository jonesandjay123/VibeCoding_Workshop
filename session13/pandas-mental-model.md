## 第一部分：Jupyter 三個概念

| 概念 | 一句話 | 日文 |
| :--- | :--- | :--- |
| Notebook | 整本實驗記錄本，一個檔案 | ノートブック |
| Cell | 一個小格子，寫一段代碼或文字，Shift+Enter 執行 | セル |
| Kernel | 在背後真正跑 Python 的大腦；Cell 只是送指令的窗口 | カーネル |

**為什麼重要：** 你以為刪掉一個 cell 就沒事了？它的變數還活在 Kernel 裡。這就是下面三大坑的根源。

---

## Jupyter 三大坑＋解法

### 坑 1：亂序執行

```python
# 你以為是從上往下跑的，但 Cell 可以跳著跑！
# Cell 1: x = 10
# Cell 2: x = x + 5 → 你改成 x = x + 100，但只跑了 Cell 2，沒重跑 Cell 1
# 結果：x 是 115，不是 110！
```

**解法：** 懷疑人生時，Kernel → Restart & Run All，從頭乾淨跑一次。

### 坑 2：變數殘留

```python
# 你把寫著 x = 100 的 cell 刪掉了
# 但 print(x) 還是印得出 100！
# 因為：刪掉 cell ≠ 刪掉變數。變數活在 Kernel 裡。
```

**解法：** Kernel → Restart，乾淨重來。

### 坑 3：看不懂執行狀態

| Cell 左邊長這樣 | 意思 |
| :--- | :--- |
| `[*]` | 正在跑，等一下 |
| `[3]` | 已經跑完，這是第 3 個跑的 |
| 空白 | 還沒跑過 |

**萬用解法（記住這一個就夠）：** 出任何怪問題 → **Kernel → Restart & Run All**。

## 第二部分：Pandas 表格思維

```text
DataFrame ＝ 一張 Excel 表
  ├─ 每一行（row）＝ 一筆記錄
  ├─ 每一列（column）＝ 一個欄位 ＝ 一個 Series（一欄）
  └─ index ＝ 每一行的行號貼紙
```

**你對 Excel 會做什麼，Pandas 就能做什麼：**

| 中文意圖 | Excel 動作 | Pandas（Codex 會幫你寫） |
| :--- | :--- | :--- |
| 讀進來 | 打開檔案 | `pd.read_csv('檔名.csv')` |
| 看一眼 | 瞄一眼表格 | `df.head()` 看前 5 行 |
| 看體檢報告 | — | `df.info()` / `df.describe()` |
| 選一欄 | 點某一欄 | `df['profit']` |
| 篩幾行 | 篩選功能 | `df[df['profit'] > 20]` |
| 分組算 | 樞紐分析表 | `df.groupby('store')['profit'].sum()` |
| 畫出來 | 插入圖表 | `.plot(kind='bar')` |

**你不需要背這些，Codex 會寫。** 你需要會的是左邊那一欄：**用中文講出你想對這張表做什麼。**

## 驗算三招（永遠不要跳過）

1. **`shape` 對不對？** 讀進來先看 `df.shape`——(20 行，5 欄）跟你預期的對得上嗎？
2. **`head()` 看一眼。** 前 5 行長得合理嗎？欄位名對嗎？有沒有亂碼？
3. **抽查手算。** 特別是 `groupby` 算出來的數字，挑一個手算對答案。對上了，你才真的懂。

## 跟 Codex 協作的公式

```text
我的數據是 [幾行幾列、欄位是什麼]
我想做的是 [篩／選／算／排，具體描述]
請生成 pandas 代碼，並 print 出中間結果讓我驗算。
```

例子：

```text
我的數據是 sample-sales.csv，20 行 5 欄（門店、年份、品類、銷售額、利潤）。
我想算每個門店 5 年的利潤總和。
請生成 pandas 代碼，並把中間結果 print 出來讓我驗算。
```
