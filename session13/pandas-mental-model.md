## 1. 为什么重新跑一格，数字会变？

Notebook 是保存代码、文字说明和输出的文件。Cell 是其中的一格。Kernel 是真正执行 Python 的程序，它会记住已建立的变量。

不同格子通常把代码送给同一个 kernel，所以可以共用变量。**共用变量不代表所有格子会自动依画面顺序重新执行。** 你只跑哪一格，它就执行哪一格。

看两种不同的动作：

```python
x = 10
print(x)
```

这一格跑两次，两次都显示 10。每次都是重新把 x 设成 10。

接著跑另一格：

```python
x = x + 1
print(x)
```

第一次显示 11；只再跑这一格，会显示 12。它每次都读取目前的 x，加 1，再存回 x。

如果回去只跑第一格，x 会变回 10。第二格下方旧的 12 可能还留在画面上，但它不会自动更新；新增一格 `print(x)` 就会看到目前的值是 10。

### 删除与重启有什么不同？

- 删除 cell，是从文件里删掉那段代码。已经存在 kernel 里的变量可能还在。
- 只 Restart Kernel，会清掉原来的变量。如果还没重新定义 x 就执行 `print(x)`，会出现 `NameError`。
- Restart 后再 Run All，会从头执行目前文件的代码。如果只保留 `x = 10` 和 `print(x)` 两格，就会显示 10；若中间还保留 `x = x + 1`，它也会执行，最后就会显示 11。要看目前文件里到底有哪些格子，不能只看第一格。

先保存再重启。缺档或缺套件并不会因为重启自动修好，要看实际错误内容。

Cell 旁的数字通常是执行计数，不是行号，也不保证代码成功。`[*]` 通常表示还在执行。保存过的输出可能是旧的，应以本次重跑结果为准。

## 2. pd 和 df 是什么？

```python
import pandas as pd
df = pd.read_csv(csv_path)
```

第一句载入 pandas，并用 pd 作为简称。第二句读取 CSV，把读到的表存进名叫 df 的变量。

df 是作者取的名字，不是 Python 固定要求的名字。也可以叫 sales_table，但后面引用这张表的地方就要使用同一个名字。`csv_path` 则是前面准备好的文件位置。

Pandas 是协助 Python 处理表格的套件。DataFrame 是它用来表示二维表格的数据结构，可以先想成一张有字段名称的工作表。

## 3. 为什么 shape 说有 20 行，画面却只有 5 行？

`df.shape` 查看整张表的大小。本课得到 `(20, 5)`，顺序是 20 行、5 栏。

`df.head()` 只预览前 5 行，让你快速看看内容。它没有把后面 15 行删掉。

本课一行代表一家门店的一年。共有 4 家门店，每家 5 年，因此是 20 行。sales 与 profit 的单位都设定为万元人民币。

category 是当年的主力品类标签。例如 A 店 2021 年标「电子」，不代表那年全部 18 万元利润都来自电子商品。我们没有每个品类的金额明细，所以不能用这栏算真正的品类利润占比。

## 4. 筛选后是 9 行，为什么只显示 3 栏？

```python
filtered = df[df["profit"] > 20]
print(filtered[["store", "year", "profit"]])
```

第一句只保留利润大于 20 万元的行。在本课样本中，得到 9 行，仍有原本全部 5 栏。

第二句另外指定只显示 store、year、profit 三栏。少显示两栏，是因为第二句选了显示范围，不是筛选把字段删掉。

大于 20 的 9 行，来自 A 店 4 行和 C 店 5 行。如果改成大于 30，会剩 5 行；恰好等于 30 的行不会留下。原表 df 没有被这两句改掉。

## 5. groupby 到底做了什么？

先看 A 店五年的利润：18、22、25、30、35。把这五个数字相加，得到 130 万元。

B、C、D 也各自做同样的事：

| 原本的数据 | 合并后的结果 |
| :--- | :--- |
| A 店五年的 5 行 | A：130 万元 |
| B 店五年的 5 行 | B：71 万元 |
| C 店五年的 5 行 | C：193 万元 |
| D 店五年的 5 行 | D：62 万元 |

下面这句就是把这个动作一次做完：

```python
totals = df.groupby("store")["profit"].sum()
```

它使用完整的 df。按 store 把同一家店放成一组，选 profit 栏，将每组的利润相加。原本 20 行变成 4 个总数。

这是五年总和，已经把每年数字合并了。如果想看逐年变化，就要回到仍保留年份的数据，不能直接把 totals 当成趋势。

## 6. dtype、缺值、重复，是同一件事吗？

不是，它们分别回答不同问题：

- `df.dtypes`：每一栏目前被当成什么数据类型？例如整数或文字。
- `df.isna().sum()`：每一栏有几格被判定为缺值？本样本每栏都是 0。
- `df.duplicated(["store", "year"]).sum()`：同店同年是否重复？本样本是 0。

看到异常先查原因。某份数据如果一行是一张订单，同店同年有多行就很正常，不能照搬本样本的规则删数据。

## 7. Series 的一维是指只有一个数字吗？（选读）

不是。`df["profit"]` 得到一个 Series，里面有 20 个利润值。`(20,)` 表示它有 20 个元素，不是只剩一个数字。

`df[["profit"]]` 则保留 DataFrame 的表格形式，大小是 `(20, 1)`：20 行、1 栏。它们只是结构不同，没有谁比较高阶。

先用得上的形式即可，不需要背括号差异。本数据的栏名是小写 profit；如果写成 Profit，Python 会把它视为另一个名称。

## 8. assert 为什么什么都没印？（遇到时再看）

```python
assert totals["门店A"] == 130, "A 店合计不是预期的 130"
```

assert 是检查条件的语句。条件成立时，它通常不显示任何东西；不成立时，会停止并显示 `AssertionError` 及后面的讯息。

所以「没有输出」不代表没执行。如果只是想看到数字，要用 `print(totals["门店A"])`。

Assert 只会检查你写的条件。即使通过，也不能证明题目理解正确。教师答案里的固定数字只适用于本合成样本；换数据或改年份时，检查值也要一起改。
