## 1. 為什麼重新跑一格，數字會變？

Notebook 是保存代碼、文字說明和輸出的文件。Cell 是其中的一格。Kernel 是真正執行 Python 的程序，它會記住已建立的變數。

不同格子通常把代碼送給同一個 kernel，所以可以共用變數。**共用變數不代表所有格子會自動依畫面順序重新執行。** 你只跑哪一格，它就執行哪一格。

看兩種不同的動作：

```python
x = 10
print(x)
```

這一格跑兩次，兩次都顯示 10。每次都是重新把 x 設成 10。

接著跑另一格：

```python
x = x + 1
print(x)
```

第一次顯示 11；只再跑這一格，會顯示 12。它每次都讀取目前的 x，加 1，再存回 x。

如果回去只跑第一格，x 會變回 10。第二格下方舊的 12 可能還留在畫面上，但它不會自動更新；新增一格 `print(x)` 就會看到目前的值是 10。

### 刪除與重啟有什麼不同？

- 刪除 cell，是從文件裡刪掉那段代碼。已經存在 kernel 裡的變數可能還在。
- 只 Restart Kernel，會清掉原來的變數。如果還沒重新定義 x 就執行 `print(x)`，會出現 `NameError`。
- Restart 後再 Run All，會從頭執行目前文件的代碼。如果只保留 `x = 10` 和 `print(x)` 兩格，就會顯示 10；若中間還保留 `x = x + 1`，它也會執行，最後就會顯示 11。要看目前文件裡到底有哪些格子，不能只看第一格。

先保存再重啟。缺檔或缺套件並不會因為重啟自動修好，要看實際錯誤內容。

Cell 旁的數字通常是執行計數，不是行號，也不保證代碼成功。`[*]` 通常表示還在執行。保存過的輸出可能是舊的，應以本次重跑結果為準。

## 2. pd 和 df 是什麼？

```python
import pandas as pd
df = pd.read_csv(csv_path)
```

第一句載入 pandas，並用 pd 作為簡稱。第二句讀取 CSV，把讀到的表存進名叫 df 的變數。

df 是作者取的名字，不是 Python 固定要求的名字。也可以叫 sales_table，但後面引用這張表的地方就要使用同一個名字。`csv_path` 則是前面準備好的檔案位置。

Pandas 是協助 Python 處理表格的套件。DataFrame 是它用來表示二維表格的資料結構，可以先想成一張有欄位名稱的工作表。

## 3. 為什麼 shape 說有 20 行，畫面卻只有 5 行？

`df.shape` 查看整張表的大小。本課得到 `(20, 5)`，順序是 20 行、5 欄。

`df.head()` 只預覽前 5 行，讓你快速看看內容。它沒有把後面 15 行刪掉。

本課一行代表一家門店的一年。共有 4 家門店，每家 5 年，因此是 20 行。sales 與 profit 的單位都設定為萬元人民幣。

category 是當年的主力品類標籤。例如 A 店 2021 年標「電子」，不代表那年全部 18 萬元利潤都來自電子商品。我們沒有每個品類的金額明細，所以不能用這欄算真正的品類利潤佔比。

## 4. 篩選後是 9 行，為什麼只顯示 3 欄？

```python
filtered = df[df["profit"] > 20]
print(filtered[["store", "year", "profit"]])
```

第一句只保留利潤大於 20 萬元的行。在本課樣本中，得到 9 行，仍有原本全部 5 欄。

第二句另外指定只顯示 store、year、profit 三欄。少顯示兩欄，是因為第二句選了顯示範圍，不是篩選把欄位刪掉。

大於 20 的 9 行，來自 A 店 4 行和 C 店 5 行。如果改成大於 30，會剩 5 行；恰好等於 30 的行不會留下。原表 df 沒有被這兩句改掉。

## 5. groupby 到底做了什麼？

先看 A 店五年的利潤：18、22、25、30、35。把這五個數字相加，得到 130 萬元。

B、C、D 也各自做同樣的事：

| 原本的資料 | 合併後的結果 |
| :--- | :--- |
| A 店五年的 5 行 | A：130 萬元 |
| B 店五年的 5 行 | B：71 萬元 |
| C 店五年的 5 行 | C：193 萬元 |
| D 店五年的 5 行 | D：62 萬元 |

下面這句就是把這個動作一次做完：

```python
totals = df.groupby("store")["profit"].sum()
```

它使用完整的 df。按 store 把同一家店放成一組，選 profit 欄，將每組的利潤相加。原本 20 行變成 4 個總數。

這是五年總和，已經把每年數字合併了。如果想看逐年變化，就要回到仍保留年份的資料，不能直接把 totals 當成趨勢。

## 6. dtype、缺值、重複，是同一件事嗎？

不是，它們分別回答不同問題：

- `df.dtypes`：每一欄目前被當成什麼資料型別？例如整數或文字。
- `df.isna().sum()`：每一欄有幾格被判定為缺值？本樣本每欄都是 0。
- `df.duplicated(["store", "year"]).sum()`：同店同年是否重複？本樣本是 0。

看到異常先查原因。某份資料如果一行是一張訂單，同店同年有多行就很正常，不能照搬本樣本的規則刪資料。

## 7. Series 的一維是指只有一個數字嗎？（選讀）

不是。`df["profit"]` 得到一個 Series，裡面有 20 個利潤值。`(20,)` 表示它有 20 個元素，不是只剩一個數字。

`df[["profit"]]` 則保留 DataFrame 的表格形式，大小是 `(20, 1)`：20 行、1 欄。它們只是結構不同，沒有誰比較高階。

先用得上的形式即可，不需要背括號差異。本資料的欄名是小寫 profit；如果寫成 Profit，Python 會把它視為另一個名稱。

## 8. assert 為什麼什麼都沒印？（遇到時再看）

```python
assert totals["門店A"] == 130, "A 店合計不是預期的 130"
```

assert 是檢查條件的語句。條件成立時，它通常不顯示任何東西；不成立時，會停止並顯示 `AssertionError` 及後面的訊息。

所以「沒有輸出」不代表沒執行。如果只是想看到數字，要用 `print(totals["門店A"])`。

Assert 只會檢查你寫的條件。即使通過，也不能證明題目理解正確。教師答案裡的固定數字只適用於本合成樣本；換資料或改年份時，檢查值也要一起改。
