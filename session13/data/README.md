# 這份練習資料代表什麼？

`sample-sales.csv` 是合成教學資料，不是真實商店、客戶或學校作業的資料。原有 20 行數值保持不變，本課使用以下設定來解讀。

## 先看一行

第一行是門店 A 的 2021 年：銷售額 120 萬元，利潤 18 萬元。「萬元人民幣」是本練習約定的金額單位。

一行代表**一家門店的一年合計**。共有 A、B、C、D 四家店，每家五年，因此是 4 × 5 = 20 行。

| 欄位 | 用一句話說明 |
| :--- | :--- |
| `store` | 哪一家門店，例如門店 A。 |
| `year` | 哪一年，範圍是 2021–2025。 |
| `category` | 這家店這一年的主力品類標記。它不是各品類的金額明細。 |
| `sales` | 這家店這一年的銷售額合計，單位是萬元人民幣。 |
| `profit` | 這家店這一年的利潤合計，單位是萬元人民幣。 |

## category 最容易誤讀

第一行標記「電子」，但那一行的 18 萬元仍是門店 A 整年的利潤。我們不知道其中有多少來自電子、服裝或食品。

因此，不能按 category 分組後，就把得到的總數說成「各品類真正貢獻的利潤」。要回答這個問題，需要另外取得按品類拆分的金額資料。

## 哪些檢查只適用於這份樣本？

本樣本沒有缺值。同一家門店、同一年只出現一行，所以 store 和 year 合起來不重複。

換成真實資料時，先重新確認一行代表什麼。如果一行是一張訂單，同店同年出現很多行就很正常；不能套用本例的假設刪行。

本課只把金額加總，不把年份加總。平均數、比率與百分比也不能直接當金額相加。發現缺值時先查原因，缺值不一定代表 0。
