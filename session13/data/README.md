# 練習資料說明

`sample-sales.csv` 為合成教學資料，與任何真實商店、客戶或學校作業無關。原有 20 行數值保持不變，本課明確約定以下解讀。

| 欄位 | 意義 | 型別／單位 |
| :--- | :--- | :--- |
| `store` | 門店標籤 A–D | 文字 |
| `year` | 年份 2021–2025 | 整數 |
| `category` | 該店該年的主力品類標記 | 文字；不是品類明細 |
| `sales` | 該店該年的銷售額合計 | 萬元（人民幣；練習設定） |
| `profit` | 該店該年的利潤合計 | 萬元（人民幣；練習設定） |

**粒度：** 一行＝一家店的一年；`store`＋`year` 聯合唯一，共 4×5＝20 行、5 欄。無缺值、無重複店年；真實資料必須重新檢查，不能照搬此假定。

`category` 會隨年份改變。把某行的全部利潤視為該品類的利潤是錯誤歸因，因此不以此做「各品類利潤佔比」。若要回答那個問題，需要按店、年、品類拆分的明細。

本課只加總金額，不把年份加總，也不把平均數、比率或百分比直接當金額相加。缺值不等於 0；發現重複鍵時先釐清粒度，不隨手刪行或改成平均以掩蓋問題。
