# 这份练习数据代表什么？

`sample-sales.csv` 是合成教学数据，不是真实商店、客户或学校作业的数据。原有 20 行数值保持不变，本课使用以下设定来解读。

## 先看一行

第一行是门店 A 的 2021 年：销售额 120 万元，利润 18 万元。「万元人民币」是本练习约定的金额单位。

一行代表**一家门店的一年合计**。共有 A、B、C、D 四家店，每家五年，因此是 4 × 5 = 20 行。

| 字段 | 用一句话说明 |
| :--- | :--- |
| `store` | 哪一家门店，例如门店 A。 |
| `year` | 哪一年，范围是 2021–2025。 |
| `category` | 这家店这一年的主力品类标记。它不是各品类的金额明细。 |
| `sales` | 这家店这一年的销售额合计，单位是万元人民币。 |
| `profit` | 这家店这一年的利润合计，单位是万元人民币。 |

## category 最容易误读

第一行标记「电子」，但那一行的 18 万元仍是门店 A 整年的利润。我们不知道其中有多少来自电子、服装或食品。

因此，不能按 category 分组后，就把得到的总数说成「各品类真正贡献的利润」。要回答这个问题，需要另外取得按品类拆分的金额数据。

## 哪些检查只适用于这份样本？

本样本没有缺值。同一家门店、同一年只出现一行，所以 store 和 year 合起来不重复。

换成真实数据时，先重新确认一行代表什么。如果一行是一张订单，同店同年出现很多行就很正常；不能套用本例的假设删行。

本课只把金额加总，不把年份加总。平均数、比率与百分比也不能直接当金额相加。发现缺值时先查原因，缺值不一定代表 0。
