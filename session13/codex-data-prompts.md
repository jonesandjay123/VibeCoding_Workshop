# 和 AI 一起釐清問題：一次只請它幫一件事

先選眼前的一個問題，再使用下面合適的模板。不需要把全部模板貼給 AI，也不要求 AI 一次完成整份作業。

Codex 可優先使用，但它能否看到檔案、執行 Python 或修改 notebook，取決於當下工具與權限。不能執行時，請它明說尚未測試；由自己在已確認的 kernel 執行。

## 1. 我還不確定自己需要什麼幫助

```text
我最近在做這個題目：[只描述題目，不貼私人資料]。
我已經能做到：[目前進度]。
現在卡在：[一個具體問題]。
請一次只問我一個問題，幫我確認接下來最值得處理哪一步。
先不要把整份作業做完，也不要先安排一整套教學。
```

## 2. 我看不懂這一小段代碼

```text
這段代碼是：[貼必要的幾行]。
目前結果是：[文字，或已去除敏感資訊的截圖]。
我不明白的是：[例如為什麼表有 20 行，卻只顯示 5 行]。
請先用完整、簡單的句子解釋。
一次只說一個動作，指出我應看到什麼，以及為什麼會這樣。
先不要加入其他語法或重寫整份 notebook。
```

## 3. 我想得到一個數字或一張表

```text
我想回答的問題是：[例如 2025 年各家門店的利潤是多少]。
我的資料一行代表：[例如一家店的一年]。
需要的欄位是：[欄位名稱]，金額單位是：[單位]。
請先確認我問的範圍，再只給下一步需要的代碼。
先顯示中間表，不要立刻畫圖。
等我執行並核對後，再決定下一步。
```

合成樣本的一個核對方式：2025 年應只有 A、B、C、D 四行，而不是將全部五年直接相加。真實資料的預期行數需另外確認。

## 4. AI 畫出圖了，但我不知道是否正確

```text
題目要回答：[一句話]。
AI 使用的處理代碼是：[必要片段]。
畫圖前的結果表是：[可分享的最少資料]。
請先檢查它使用的年份、欄位和加總方式，是否符合題目。
請指出一個我能自己從原始資料核對的數字。
不要只因為程式能執行，就說分析正確。
```

## 5. 我想試一個小改動

```text
目前代碼能做到：[目前結果]。
我想只改：[一個年份、門檻或欄位]。
請指出與這個改動有關的那幾行，讓我自己修改。
在執行前，先幫我確認大概會有哪些變化。
若標題、單位、檔名或檢查值也需要同步修改，請分別提醒我。
不要無關地改寫其他部分。
```

## 6. 執行失敗了

```text
我使用的是：[Notebook、Antigravity、VS Code 等實際工具]。
目前 kernel 的 Python 路徑是：[去除私人資訊後的路徑]。
剛執行的代碼：[最小必要片段]。
錯誤訊息：[已遮住姓名、學號、token、私人路徑的 traceback]。
請先說明這是缺套件、缺檔、代碼問題，還是執行順序問題。
一次建議一個小修正，讓我執行後確認結果。
不要未經確認就重建環境或重寫整份檔案。
```

## 7. 導師在語音中請求解釋

```text
學生目前想做：[目標]。
我看到她的畫面是：[口述畫面或提供可分享截圖]。
她剛執行：[操作]，結果顯示：[結果]。
她不理解：[卡點]。
請先給我一句可以對她說的白話解釋，再給一個小問題確認她理解了。
如果你還缺資料，先問我，不要假定你看得到她的螢幕。
```

## 分享前先確認

本課合成資料可以用於練習。學生的真實作業、成績、同學資料、私人聊天及憑證，不能因為需要解釋就直接上傳或提交到公開 repo。先確認使用權與學校的 AI 規定，只分享必要而且可分享的部分。

有缺值或重複時，也先問資料代表什麼，不讓 AI 為了「跑通」直接刪行、填 0 或改成平均。
