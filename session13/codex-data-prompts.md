# Codex 數據分析提問模板：每次只走一步

Codex 是本課首選輔助工具；能否讀檔、執行 Python、修改 notebook 取決於當天的介面與權限。先確認；不能執行時讓它給一小段代碼，由自己在已確認的 Python kernel 跑。已可用的 Trae／通義靈碼也可用同樣模板。

## 開場約定：AI 當教練

```text
我正在學 Jupyter 和 pandas。請先提示，不要直接完成整份作業。
每次只處理一個小問題、一個 cell，先問我預測結果的形狀或數字。
等我執行、貼出已去除敏感資訊的結果，並用自己的話解釋後，再繼續。
若你沒有實際執行環境，請明說「尚未執行」，不要假裝測過。
```

## 1. 先讀懂一張表

```text
我要讀本課合成資料 data/sample-sales.csv。
一行是一家店一年；欄位 store/year/category/sales/profit。
sales、profit 單位是萬元（人民幣）；category 只是主力品類標記。
先幫我確認工作目錄與檔案路徑，給讀入和查看 shape 的一小段 pandas 代碼。
我預測是 20 行 5 欄。先不要畫圖、清洗或總結發現。
```

後續再分開問：「如何檢查每欄型別與缺值？」「如何檢查 store＋year 是否唯一？」不能用 `head()` 代替全表檢查。

## 2. 選欄／篩行：先預測一個改動

```text
我想只保留 profit > 20 的行，原始 df 不要覆寫。
請先問我預測會剩幾行，再提示如何寫。
跑通後，我會親手把門檻改成 30，解釋哪幾行會消失，再執行驗證。
```

## 3. 分組：先確定問題與口徑

```text
我要比較各門店 2021–2025 五年的利潤總和。
請先問我應按哪欄分組、用 sum 還是 mean，以及結果會有幾組。
給一小段代碼印出分組表，暫時不畫圖。
我會手算 A 的 18+22+25+30+35，再抽查 B，最後核對全表合計。
不要把 year 或 sales 也一起加總；不要把五年總和解讀成年度趨勢。
```

## 4. 圖表：使用已核對的表

```text
我已核對這張 [2025年各店利潤表／各店五年合計表／逐年利潤表]。
我要回答 [一句問題]，我選 [條形圖／折線圖]，原因是 [比較／時間趨勢]。
先讓我指出 X 軸、Y 軸、年份範圍和單位，再給最小繪圖代碼。
使用 matplotlib；標明萬元和合成資料，圖例可讀。
如果沒有可用中文字型，先用英文標籤，不自動下載安裝。
先保存到 outputs/[檔名].png 再 show；告訴我實際路徑，我會打開檢查。
趨勢圖必須保留年份、由小到大排序，不得用五年總和代替。
```

## 5. 除錯：用證據縮小問題

```text
我在 [Notebook/JupyterLab/VS Code] 的 Python kernel 跑這個 cell。
工作目錄：[去除個資後的路徑]
相關代碼：[貼最小必要片段]
報錯：[已遮住姓名、學號、私人路徑、token 等的 traceback]
最後成功的一步：[說明]
請先解釋錯誤類型，區分路徑、套件、代碼與殘留狀態的問題。
只建議一個最小改動，讓我預測改動效果後再跑；不要一次重寫全部。
```

## 6. 遇到髒資料（課後延伸，不佔本堂主線）

```text
請先報告缺值、重複鍵、異常型別的數量及相關行，不要自動刪除或填 0。
說明它們可能如何影響我的問題，提出處理選項，等我確認資料意義。
經確認後，另存新檔，保留原始資料，列出改動前後行數及原因。
```

只分享有權使用、已去識別的必要資料；本堂一律用合成樣本。Notebook 輸出和 traceback 也可能含個資。學校作業先遵守 AI 使用規定，能解釋、能重現才算完成。
