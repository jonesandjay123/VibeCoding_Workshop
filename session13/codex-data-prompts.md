# Codex 數據分析提問模板

> Codex 是 autonomous coding agent：你給它一個講清楚的任務，它能自己跑完。
> 但前提是**任務要講清楚**。這份模板教你怎麼講。

---

## 萬用公式

```text
這個檔案有幾行幾列，每一欄是什麼
我想知道什麼（一句話）
我要什麼形式的結果（表格／圖／檔案）
請把中間結果 print 出來讓我檢查
```

---

## 模板 1：探索性分析（拿到新數據先做這個）

```text
請幫我對 [檔名.csv] 做探索性分析：
- 數據形狀：先告訴我幾行幾列
- 每一欄的類型、有沒有缺失值
- 數值欄位的基本統計（平均、最大、最小）
- 畫 2–3 張圖幫我直觀理解數據分佈
- 最後用中文總結 3 個你發現的重點

請把每一步的中間結果都 print 出來。
```

## 模板 2：數據清洗

```text
[檔名.csv] 需要清洗：
- [某欄] 有缺失值，請告訴我有多少，並建議處理方式（刪除／填補）
- [某欄] 的格式不統一（比如日期有兩種寫法），請統一
- 請檢查有沒有重複的行

清洗完存成 [新檔名.csv]，並告訴我你改了什麼。
```

## 模板 3：分組統計（最常用）

```text
[檔名.csv] 有 [X] 行，欄位是 [列出來]。
請按 [某欄] 分組，計算 [某欄] 的 [總和／平均／個數]，
結果按 [某欄] 排序，並畫一張條形圖。

請先 print 出分組結果的表格讓我驗算，確認後再畫圖。
```

## 模板 4：畫圖（溝通級）

```text
請用 matplotlib 畫 [折線圖／條形圖／餅圖]：
- 數據：[描述]
- 標題：[中文標題]
- X 軸：[什麼]，Y 軸：[什麼，單位]
- 中文標籤要正常顯示（不要方框）
- 圖例清楚，顏色好看一點
- 存成 [檔名.png]，不要只顯示在螢幕上

畫完請告訴我這張圖在回答什麼問題。
```

**提醒：** 中文變方框是 matplotlib 的經典坑。如果出現了，直接跟 Codex 說「中文標籤顯示成方框了，幫我修」，它知道怎麼處理（Session 12 踩過這個坑）。

## 模板 5：除錯（出錯時用）

```text
這段代碼報錯了：
[貼上代碼]
報錯訊息：
[貼上完整的報錯訊息]

請告訴我：
1. 錯在哪裡（用中文解釋原因）
2. 怎麼修
```

**關鍵：** 永遠貼**完整**的報錯訊息，不要只貼最後一行。Codex 需要完整的 traceback 才能定位。

---

## 三個好習慣

1. **一次只交代一件事。** 「先幫我讀進來看看」→ 確認對了 → 「再幫我分組算」。不要一次丟五個需求。
2. **永遠要中間結果。** 加一句「請把中間結果 print 出來」，你才有東西可以驗算。
3. **不對就叫它重做，不要自己硬改。** 你是需求方＋驗算方，寫代碼是它的工作。
