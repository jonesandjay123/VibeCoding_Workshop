# 和 AI 一起厘清问题：一次只请它帮一件事

先选眼前的一个问题，再使用下面合适的模板。不需要把全部模板贴给 AI，也不要求 AI 一次完成整份作业。

Codex 可优先使用，但它能否看到文件、执行 Python 或修改 notebook，取决于当下工具与权限。不能执行时，请它明说尚未测试；由自己在已确认的 kernel 执行。

## 1. 我还不确定自己需要什么帮助

```text
我最近在做这个题目：[只描述题目，不贴私人数据]。
我已经能做到：[目前进度]。
现在卡在：[一个具体问题]。
请一次只问我一个问题，帮我确认接下来最值得处理哪一步。
先不要把整份作业做完，也不要先安排一整套教学。
```

## 2. 我看不懂这一小段代码

```text
这段代码是：[贴必要的几行]。
目前结果是：[文字，或已去除敏感资讯的截图]。
我不明白的是：[例如为什么表有 20 行，却只显示 5 行]。
请先用完整、简单的句子解释。
一次只说一个动作，指出我应看到什么，以及为什么会这样。
先不要加入其他语法或重写整份 notebook。
```

## 3. 我想得到一个数字或一张表

```text
我想回答的问题是：[例如 2025 年各家门店的利润是多少]。
我的数据一行代表：[例如一家店的一年]。
需要的字段是：[字段名称]，金额单位是：[单位]。
请先确认我问的范围，再只给下一步需要的代码。
先显示中间表，不要立刻画图。
等我执行并核对后，再决定下一步。
```

合成样本的一个核对方式：2025 年应只有 A、B、C、D 四行，而不是将全部五年直接相加。真实数据的预期行数需另外确认。

## 4. AI 画出图了，但我不知道是否正确

```text
题目要回答：[一句话]。
AI 使用的处理代码是：[必要片段]。
画图前的结果表是：[可分享的最少数据]。
请先检查它使用的年份、字段和加总方式，是否符合题目。
请指出一个我能自己从原始数据核对的数字。
不要只因为程序能执行，就说分析正确。
```

## 5. 我想试一个小改动

```text
目前代码能做到：[目前结果]。
我想只改：[一个年份、门槛或字段]。
请指出与这个改动有关的那几行，让我自己修改。
在执行前，先帮我确认大概会有哪些变化。
若标题、单位、档名或检查值也需要同步修改，请分别提醒我。
不要无关地改写其他部分。
```

## 6. 执行失败了

```text
我使用的是：[Notebook、Antigravity、VS Code 等实际工具]。
目前 kernel 的 Python 路径是：[去除私人资讯后的路径]。
刚执行的代码：[最小必要片段]。
错误讯息：[已遮住姓名、学号、token、私人路径的 traceback]。
请先说明这是缺套件、缺档、代码问题，还是执行顺序问题。
一次建议一个小修正，让我执行后确认结果。
不要未经确认就重建环境或重写整份文件。
```

## 7. 导师在语音中请求解释

```text
学生目前想做：[目标]。
我看到她的画面是：[口述画面或提供可分享截图]。
她刚执行：[操作]，结果显示：[结果]。
她不理解：[卡点]。
请先给我一句可以对她说的白话解释，再给一个小问题确认她理解了。
如果你还缺数据，先问我，不要假定你看得到她的屏幕。
```

## 分享前先确认

本课合成数据可以用于练习。学生的真实作业、成绩、同学数据、私人聊天及凭证，不能因为需要解释就直接上传或提交到公开 repo。先确认使用权与学校的 AI 规定，只分享必要而且可分享的部分。

有缺值或重复时，也先问数据代表什么，不让 AI 为了「跑通」直接删行、填 0 或改成平均。
