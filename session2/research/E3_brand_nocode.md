## 3 ✦ 從個人網站起步 → 品牌的成長路線

```
Phase 0 — 驗證（0 元）
├── 用 Carrd 做一頁 Landing Page
├── 用 Notion 整理品牌故事 & 產品想法
├── IG/小紅書先跑內容，觀察反應
└── 收集 email（ConvertKit 免費 1K 人）

Phase 1 — 建站（$0–15/mo）
├── Framer 或 Webflow 做正式品牌站
├── 加 Blog / 作品集，開始 SEO
├── Canva 統一視覺 identity
└── 如果要賣東西 → Shopify or Gumroad

Phase 2 — 成長（$15–50/mo）
├── CMS 管理動態內容（食譜、商品、文章）
├── Email 養名單、做 newsletter
├── Zapier 串接自動化（下單通知、回信等）
└── 用 Google Analytics 追蹤數據

Phase 3 — 規模化
├── Custom domain + 品牌 email
├── 客製功能（可以在 Webflow 加自己的 HTML/CSS/JS）
│   → 這就是你已有的 HTML/CSS 技能派上用場的時候！
├── 考慮加 member area / 付費內容
└── 團隊協作（Notion、Figma、Slack）
```

> **關鍵洞察**：「先行銷再建站」—— FemaleSwitch 強調，很多學生花太多時間建站，卻忽略驗證需求。先在社群測試反應，再投入建站。

## 6 ✦ 給這位學生的具體建議

### 你已經有的優勢
- ✅ 會 HTML/CSS → 可以在 Webflow/Framer 裡客製細節，比純 no-code 用戶更有彈性
- ✅ 大二 → 有時間實驗、有學生免費工具

### 建議路線

1. **Week 1**：用 Carrd 做一頁品牌概念站，社群先跑起來
2. **Week 2-3**：用 Framer AI 生成正式品牌站骨架，用你的 CSS 技能微調
3. **Month 2**：加 Blog（SEO）、Email 收集、視覺統一
4. **Month 3+**：如果要賣東西 → Shopify / Gumroad；如果是內容品牌 → Webflow CMS

### ⚠️ 常見陷阱
- 別花 3 個月「完美化」網站 → 先上線 80 分版本
- 別一開始就付費 → 免費工具足以驗證
- 別只建站不行銷 → 內容 + 社群 + SEO 同步跑
