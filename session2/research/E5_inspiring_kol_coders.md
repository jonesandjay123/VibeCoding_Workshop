# E5: 從 Coding 起步的 KOL / 影響力人物

> 研究日期：2026-02-04
> 目的：展示「學 coding → 建立個人品牌 → 影響更多人」的真實路徑

---

## 📌 核心訊息

**Coding 不只是找工作的工具，它是打開「個人品牌 × 內容創作」大門的鑰匙。** 以下這些人，從學 code 開始，最終成為擁有數十萬甚至數百萬粉絲的 KOL。

## 🌟 案例一：Lydia Hallie — 自學 Coder → 頂級技術 KOL

- **背景**：荷蘭女生，沒有 CS 學位，15 歲在 Tumblr 上開始自學 HTML/CSS/jQuery
- **KOL 之路**：
  - 17 歲在 Medium 寫文章「Advice from a 19 Year Old Girl and Software Developer」爆紅
  - 在 Instagram 開創「筆電自拍 + code snippet」風格（laptop selfie phenomenon）
  - 製作 JavaScript 視覺化教學內容，在 Dev.to 和社群大量分享
- **現在**：Vercel Staff DevRel Engineer、國際講者、課程講師、技術 influencer
- **粉絲規模**：Twitter/X 數十萬 followers
- **教學啟示**：技術內容 + 個人風格 = 獨特定位。她證明了「年輕 + 非科班 + 女性」不是劣勢
- 📎 [DevJourney Podcast](https://devjourney.info/Guests/88-LydiaHallie.html) | [nocsdegree 專訪](https://www.nocsdegree.com/an-interview-with-lydia-hallie-about-how-she-learned-coding/) | [Frontend Masters Podcast](https://www.youtube.com/watch?v=MDz2_Zdzhos)

## 📊 Coding KOL 的共同模式

```
1. 開始學 coding（通常是自學/bootcamp）
     ↓
2. 邊學邊分享過程（blog/Twitter/YouTube/Instagram）
     ↓
3. 找到自己的風格和定位（幽默型/教學型/記錄型/技術深度型）
     ↓
4. 建立社群 + 持續產出
     ↓
5. 從「學習者」變成「教學者」→ 影響力 + 事業機會
```

---

## 💡 給課程設計的 Takeaways

1. **學 coding 的過程本身就是內容**：不用等到「很強」才開始分享，記錄學習旅程就是最好的 content
2. **個人品牌 = 技術 × 個性**：Cassidy 的幽默、Lydia 的視覺風格、Tina 的親切感 —— 每個人都有獨特定位
3. **中文市場機會巨大**：華語 coding KOL 相對英語世界少很多，特別是「講人話」的初學者友善內容
4. **非科班是賣點不是弱點**：觀眾更能 relate to「跟我一樣從零開始」的創作者
5. **Coding → Content → Business**：Clément 的 AlgoExpert、Nana 的 bootcamp —— 技術 + 內容 = 創業
6. **女性 KOL 正在崛起**：Lydia、Tina、Cassidy、Nana、Ann —— 女性在 tech content 領域有天然優勢（打破刻板印象 = 更有故事性）
7. **GitHub 是你的第二張臉**：經營 GitHub profile 就像經營 Instagram，是展示能力的最佳管道
