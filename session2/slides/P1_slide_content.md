## Slide 8 — Git = 電玩存檔

**標題：** 🎮 Git 就是遊戲存檔

- 打 Boss 前會先存檔 → Git 就是幫你的程式碼做這件事
- 每次存檔 = 一個 **commit**
- 搞砸了可以回到之前的存檔點
- GitHub = 雲端備份（Switch 的雲端存檔）

```
你的電腦              GitHub（雲端）
┌────────┐  push →  ┌────────┐
│ 改的檔案 │          │  備份   │
│         │ ← pull   │ （安全）│
└────────┘          └────────┘
```

> **講者備註：**
> 先問她：「你有打過 RPG 嗎？或任何有存檔的遊戲？」不管有沒有都用這個比喻。
> 「Git 就是幫你的程式碼存檔的工具。每次存檔就叫一個 commit，萬一搞砸了可以回到之前的存檔點。」

## Slide 9 — 六大指令預覽

**標題：** 今天只學這六個

| 指令 | 遊戲比喻 | 一句話 |

| `git clone` | 下載遊戲 | 把 GitHub 專案抓到電腦 |

| `git pull` | 下載雲端存檔 | 拿最新版 |

> **講者備註：**

## Slide 15 — git status：紅色 = 有改動

**標題：** 問 Git「現在什麼狀況？」

```

  modified:   index.html    ← 紅色！
```

- 紅色 = Git 說「欸，你改了東西，要存檔嗎？」
- 🎮 就像遊戲跳出「你有未儲存的進度！」

> **講者備註：**
> 「看到那個紅色的 modified 了嗎？Git 在跟你說：『我發現你改了這些東西，你要存檔嗎？』它很聰明，會自動知道你改了什麼。」
> 可以加碼教 `git diff` 看到 +/- 的對比，但不要花太多時間。

## Slide 16 — git add：紅色 → 綠色

**標題：** 選好要存的東西

```
$ git add .         ← 那個 . = 「全部都要」
$ git status

  modified:   index.html    ← 變綠色了！
```

- 紅色 → 綠色 = 已勾選、準備存檔
- 🎮 就像選好要存哪個進度

> **講者備註：**
> 「看！變綠色了！綠色 = 你已經選好要存的東西了。」
> 如果她問為什麼要先 add：「有時候你改了 5 個檔案但只想存 3 個，add 讓你選。就像拍了 20 張照片只挑 5 張放 IG。」

**標題：** 🎮 按下存檔鍵

- `-m` 後面 = 給未來自己看的備忘錄

- **讓她自己寫** commit message

> **講者備註：**

## Slide 19 — 核心循環總結


- ✅ 「我 push 上 GitHub 了！！」🎉

## Slide 22 — JS 黃金公式

**標題：** 所有 JS 都是這個公式

```
「當 ___（什麼事發生），對 ___（哪個東西），做 ___（什麼反應）」
```

- 例：「當按鈕被點擊，對整個頁面，加上深色模式」
- 例：「當滑鼠移到圖片上，對圖片，放大一點」
- 以後看到任何 code，就問自己這三個問題

> **講者備註：**
> 寫在紙上。這個公式很重要，以後教 JS demo 會一直用到。
> 「所有 JavaScript 都可以用這個公式理解。以後看到任何 code，你就問自己這三個問題。」
> 補充：「JS 你現在不需要自己從零寫。以後可以叫 AI 幫你寫，但你要能看得懂。就像不用自己做菜，但要能看懂菜單。」

## Slide 23 — API = 程式的外送平台

**標題：** API 就是叫外送 🍕

- 你用 UberEats → 不需要知道廚房長什麼樣
- 你只要在 APP 上「告訴它你要什麼」，食物就來了

| 角色 | 比喻 |
|------|------|
| 前端 | 店面（你看到的畫面）|
| API | 店員（傳話的人）|
| 後端 | 廚房（處理訂單）|
| 資料庫 | 倉庫（記住東西）|

> **講者備註：**
> 「你用 UberEats 的時候，需要知道餐廳的廚房長什麼樣嗎？不需要。你只要點餐，食物就來了。API 就是這個。」

## Slide 38 — 為什麼需要 Worker？

## Slide 40 — 貼上代碼

**標題：** Worker 代碼

讓 AI 幫忙生成，或用這個：

```javascript
export default {
  async fetch(request, env) {
    if (request.method !== "POST") {
      return new Response("Use POST", { status: 405 });
    }
    const { prompt } = await request.json();
    const res = await fetch(
      "https://generativelanguage.googleapis.com/v1beta/interactions",
      {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          "x-goog-api-key": env.GEMINI_API_KEY
        },
        body: JSON.stringify({
          model: "gemini-2.5-flash",
          input: prompt
        })
      }
    );
    const data = await res.json();
    const text = data.outputs?.find(o => o.type === "text")?.text || "";
    return new Response(JSON.stringify({ ok: true, text }), {
      headers: { 
        "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*"
      }
    });
  }
};
```

> **講者備註：**
> 這段代碼可以讓她的 AI 幫忙生成，或直接複製貼上。重點是讓她理解「這段代碼會接收網頁的請求，然後幫你去問 Google AI，再把答案傳回來」。
