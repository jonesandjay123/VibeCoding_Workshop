## Slide 8 — Git = ゲームのセーブ

**標題：** 🎮 Git はゲームのセーブ機能

- ボス戦前にセーブするよね → Git はコードの世界でそれをやるツール
- セーブ1回 = **commit** 1つ
- ミスっても前のセーブポイントに戻れる
- GitHub = クラウドバックアップ（Switch のクラウドセーブみたいなもの）

```
あなたの PC              GitHub（クラウド）
┌────────┐  push →  ┌────────┐
│変更した  │          │ バック  │
│ファイル  │ ← pull   │ アップ  │
└────────┘          └────────┘
```

> **講者備註：**
> まず聞いてみよう：「RPGとか、セーブ機能があるゲームやったことある？」やったことあってもなくてもこの例えでいく。
> 「Git ってコードのセーブ機能みたいなもの。1回セーブすることを commit って言うんだけど、もしミスっても前のセーブポイントに戻れるの。」

## Slide 9 — 6つのコマンド プレビュー

**標題：** 今日覚えるのはこの6つだけ

| コマンド | ゲームで言うと | ひとこと |
|------|---------|--------|
| `git clone` | ゲームをダウンロード | GitHub のプロジェクトを PC に取得 |
| `git status` | ステータス確認 | 「何が変わった？」 |
| `git add .` | セーブ対象を選ぶ | 「これをセーブする」 |
| `git commit -m "…"` | セーブボタンを押す | セーブ＋メモ |
| `git push` | クラウドにアップロード | GitHub に同期 |
| `git pull` | クラウドからダウンロード | 最新版を取得 |

> **講者備註：**
> 「今日覚えるのはこの6つだけ。本当に6つだけ。エンジニアが毎日使ってるのもこれだけだよ。」
> これはプレビューだから、今覚えなくてOK。あとで一つずつやっていくから。

## Slide 15 — git status：赤 = 変更あり

**標題：** Git に「今どうなってる？」って聞いてみよう


- 赤 = Git が「ねえ、変更があるけど、セーブする？」って言ってる

> **講者備註：**

## Slide 16 — git add：赤 → 緑

**標題：** セーブするものを選ぼう

- 🎮 どのセーブスロットにするか選んだ感じ

> **講者備註：**

> **講者備註：**

> 日本語でも中国語でも、好きな言語で書いてOK。
