🍕 API 外送流程
你的網頁（前端）
⬇️ fetch() 發送請求
Dog CEO 伺服器（後端）
⬇️ 從資料庫隨機挑一張
回傳 JSON { message: "圖片網址" }
⬇️ .then() 處理回傳
顯示在你的網頁上！✨
🍕 API デリバリーの流れ
あなたのページ（フロントエンド）
⬇️ fetch() でリクエスト送信
Dog CEO サーバー（バックエンド）
⬇️ データベースからランダムに1枚選ぶ
JSON を返す { message: "画像URL" }
⬇️ .then() で返ってきたデータを処理
あなたのページに表示！✨
🔍 核心程式碼

fetch('https://dog.ceo/api/breeds/image/random')
  .then(res => res.json())
  .then(data => { /* 用 data 做事 */ })

● fetch() → 發送「外送訂單」給 API
● .then() → 「然後」（等回來後做什麼）
● res.json() → 把回傳的資料解析成 JSON
● data.message → 狗狗圖片的網址
🔍 コアコード

fetch('https://dog.ceo/api/breeds/image/random')
  .then(res => res.json())
  .then(data => { /* data を使って処理 */ })

● fetch() → API に「デリバリー注文」を送る
● .then() → 「その後」（届いたら何をするか）
● res.json() → 返ってきたデータを JSON に変換
● data.message → わんこ画像の URL
