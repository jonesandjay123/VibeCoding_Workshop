✨ Demo 1：打招呼 Alert

JavaScript 最簡單的第一步！
按下按鈕 → 跳出一個小視窗 🎉 JavaScript の一番カンタンな第一歩！
ボタンを押す → ウィンドウがポップアップ 🎉

🔍 這行在幹嘛？

onclick="alert('...')"

● onclick → 「被點擊的時候」
● alert('...') → 「跳出一個小視窗，顯示裡面的文字」

👉 黃金公式：當按鈕被點擊，對瀏覽器，做跳出 alert
🔍 このコードは何してるの？

onclick="alert('...')"

● onclick → 「クリックされた時」
● alert('...') → 「ウィンドウをポップアップして、中のテキストを表示」

👉 黄金フォーミュラ：ボタンがクリックされたら、ブラウザに対して、alert を出す

💡 這是全世界最小的 JavaScript —— 只有 alert() 一個指令！
