這是我的可愛網站。
Dark Mode 可以改變整個外觀！ これは私のかわいいウェブサイト。
Dark Mode で見た目が全部変わるよ！

🔍 核心只有一行！

document.body.classList.toggle('dark-mode')

● document.body → 整個網頁的 body
● classList.toggle() → 「有就拿掉、沒有就加上」
● 'dark-mode' → 要 toggle 的 CSS class 名稱

👉 JS 只是開關，CSS 負責外觀！
🔍 コアはたった1行！

document.body.classList.toggle('dark-mode')

● document.body → ページ全体の body
● classList.toggle() → 「あれば外す、なければ付ける」
● 'dark-mode' → toggle する CSS class の名前

👉 JS はスイッチだけ、見た目は CSS の仕事！

💡 重點：JS 只做了「加/拿掉 class」這一件事，深色的樣式全部由 CSS 控制 💡 ポイント：JS は「class を付ける/外す」だけ、ダークスタイルは全部 CSS が担当
