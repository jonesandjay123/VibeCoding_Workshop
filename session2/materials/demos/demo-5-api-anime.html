🎌 Demo 5：動漫搜尋 API

用 Jikan API（MyAnimeList 開放資料）搜動漫！
體驗 API「帶參數」的威力 ✨ Jikan API（MyAnimeList のオープンデータ）でアニメ検索！
API の「パラメータ付き」のパワーを体験 ✨

👆 輸入動漫名稱或點上面的標籤開始搜尋！ 👆 アニメ名を入力するか、上のタグをクリックして検索！
🔍 核心程式碼

fetch('https://api.jikan.moe/v4/anime?q=spy+family&limit=5')

● ?q=spy+family → 參數：搜尋關鍵字
● &limit=5 → 參數：最多回傳 5 筆

👉 參數就像 UberEats 的「不要辣」「加大」
   同一個 API，不同參數 → 不同結果！
🔍 コアコード

fetch('https://api.jikan.moe/v4/anime?q=spy+family&limit=5')

● ?q=spy+family → パラメータ：検索キーワード
● &limit=5 → パラメータ：最大5件まで返す

👉 パラメータは UberEats の「辛さ抜き」「大盛り」みたいなもの
   同じ API でも、パラメータが違えば → 結果も違う！
