## ⌨️ Git 六大指令速查

| 指令 | 🎮 電玩比喻 | 一句話說明 |
|------|-------------|-----------|
| `git clone <URL>` | 下載遊戲 | 把 GitHub 上的專案抓到你的電腦 |
| `git status` | 按 Pause 看狀態 | 「我改了什麼？存了沒？」 |
| `git add .` | 勾選要存的進度 | 「這些改動我都要存」 |
| `git commit -m "備忘"` | 按下存檔鍵 💾 | 正式記錄，附一句給未來自己的備忘 |
| `git push` | 上傳雲端存檔 ☁️ | 同步到 GitHub，全世界看得到 |
| `git pull` | 下載雲端存檔 | 從 GitHub 拿最新版本到電腦 |

### 📝 日常節奏（背這個就夠）

```
改東西 → git status → git add . → git commit -m "做了什麼" → git push
  改        看         選           存                     傳
```

## 🧠 JavaScript 黃金公式

> JS 你現在不用自己寫，但要能「讀懂」它在做什麼。所有 JS 都可以用這個公式理解：

```
「當 ___（什麼事發生），對 ___（哪個東西），做 ___（什麼反應）」
```

| 範例 | 當… | 對… | 做… |
|------|-----|-----|-----|
| 深色模式 | 按鈕被點擊 | 整個頁面 | 切換成深色 🌙 |
| 圖片放大 | 滑鼠移到圖片上 | 那張圖片 | 放大一點 |
| 複製連結 | 「Copy」按鈕被點 | 連結文字 | 複製到剪貼簿 |

## 📞 API 一句話解釋

> **API = 讓你的程式跟別的程式「點餐」的方法**

你用 UberEats 的時候，需要知道餐廳廚房長怎樣嗎？不需要。  
你只要在 APP 點餐，食物就來了。API 就是這個。

🐶 試試看：在瀏覽器貼上 `https://dog.ceo/api/breeds/image/random` → 你剛呼叫了一個 API！

## 🏪 前端 / 後端 / 資料庫 角色卡

```
┌─────────────────────────────────────────┐
│  🎨 店面裝潢（前端）                       │
│  HTML = 骨架（牆壁、櫃子）                 │
│  CSS  = 裝潢（油漆、燈光）                 │
│  JS   = 店員互動（按鈴會響、門會自動開）    │
│  ← 你已經會 HTML + CSS，前端 70% ✅       │
├─────────────────────────────────────────┤
│  📞 服務生（API）                          │
│  在店面和廚房之間傳遞訊息                   │
├─────────────────────────────────────────┤
│  👨‍🍳 廚房（後端）                          │
│  處理訂單、算運費、驗證身分                  │
├─────────────────────────────────────────┤
│  📦 倉庫（資料庫）                         │
│  記住所有商品、會員資料、訂單紀錄            │
└─────────────────────────────────────────┘
```
