## 階段步驟與實作指引

### Phase 1：開場定錨（00–10 min）

- [] 用上面的話術開場，確認學生理解「指揮官 vs 執行者」的分工。
- [] 展示課堂簡報的三道題（orders.txt），說明今天全部做完。
- [] 確認課前準備：`orders.txt` 已下載並知道放在哪。

### Phase 2：工具鏈一次到位（10–25 min）

**原則：一個 primary 能跑就好，不裝一堆。**

- [] **AI IDE：** Trae 國內版 或 通義靈碼，二選一。學生之前已有 IDE 概念，直接裝、登入。
- 若登入卡住超過 5 分鐘 → 換另一個，不要除錯。
- [] **模型：** 接 DeepSeek / Kimi / Qwen 任一，免費額度即可。只確認「能正常對話寫代碼」。
- [] **Jupyter：** 確認 `jupyter notebook` 能打開；`pip` 換清華源：
```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip install numpy pandas matplotlib seaborn
```
- [] **驗收：** 新建 notebook 跑通：
```python
import pandas as pd
print(pd.__version__)
```

> ⚠️ **Antigravity 處理原則：** 若學生問起，直接說明區域限制是結構性問題，今天不花時間除錯。等中國工具鏈跑通後，Antigravity 以後有機會再說。

### Phase 3：第一題 — 各門店每年利潤總和（25–40 min）

**這一題由導師完整示範「需求 → AI → 驗算」迴圈，後面兩題學生主導。**

- [] **讀數據：** 先讓 Agent 生成讀檔代碼，重點是先看懂數據長什麼樣：
```python
df = pd.read_csv('orders.txt', sep='\t') # 先確認分隔符！txt 可能是 \t 或,
df.head()
df.info()
```
⚠️ 分隔符是第一個實戰坑：`orders.txt` 不一定是逗號分隔，先 `head` 看原始內容再決定。

- [] **學生親口描述需求**（導師可引導，但話必須她自己說）：
> 「我想知道每一個門店、每一年的利潤總和。」

- [] **Agent 生成 groupby 代碼**，跑起來看結果。

- [] **驗算教學（本題重點）：**
- 抽查：挑一個門店一年的數字，用 `df[(df['門店']=='A') & (df['年份']==2020)]['利潤'].sum()` 手算對一次。
- 問學生：「總和跟平均有什麼不一樣？這題為什麼用總和？」（引導她想「問題是什麼」，不是背函數）

### Phase 4：第二題 — 2020 年各門店利潤條形圖，導出 png（40–65 min）

- [] **學生主導描述需求**：「畫 2020 年每個門店的利潤條形圖。」
- [] **先問選圖**：「為什麼是條形圖不是折線圖？」→ 因為是**比較**不同門店，不是看趨勢。呼應 [`chart-selection-guide.md`](./chart-selection-guide.md)。
- [] **中文亂碼坑（刻意踩）：** 第一次跑，標題用中文，大概率變方框 ☐☐☐。
- 不要預先避開，讓她親眼看到坑。
- 修法（Windows 最常見）：
```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei'] # Windows 黑體
# Mac 用 'PingFang HK'，Linux 用 'Noto Sans CJK SC'
plt.rcParams['axes.unicode_minus'] = False # 負號正常顯示
```
- 話術：「這個坑每一個在中國做數據可視化的人都踩過，妳現在踩完，以後就不會了。」
- [] **導出 png：**
```python
plt.savefig('store_profit_2020.png', dpi=150, bbox_inches='tight') # 一定要在 show() 之前！
plt.show()
```
- 解釋 `bbox_inches='tight'`：避免標題被切掉。
- [] **驗收：** 資料夾裡出現 png，圖打開中文正常、數字跟第一題對得上。

### Phase 5：第三題 — 各門店 2014–2020 利潤折線圖，導出 pdf（65–95 min）

- [] **先問問題，再選圖：**「這張圖想回答什麼問題？」→ 看**趨勢** → 折線圖。
- [] **學生描述需求，Agent 生成，跑起來。**
- [] **從探索切換到溝通視角：** 這張圖是要交作業的，問學生：
- 標題清楚嗎？（加上年份區間）
- 線太多看不清怎麼辦？（只取 Top 3 門店？加圖例？）
- 顏色區分得開嗎？
- 讓她指揮 Agent 改兩輪，體會「給別人看的圖」跟「自己看的草稿」不一樣。
- [] **導出 pdf：** `plt.savefig('store_profit_trend.pdf', format='pdf')`。
- [] **驗收：** 三道題全部完成，png + pdf 都在資料夾。

### Phase 6：選配緩衝（95–110 min）

- 若時間有剩，二選一：
- **Seaborn 初探：** 同一組數據，用 `sns.barplot` 重畫第二題，體會「同樣的圖，Seaborn 預設比較好看」。
- **customers.txt 挑戰：** 讓她自己挑簡報裡 9 道題中的一題，獨立走完「需求→AI→驗算」。
- 若時間不夠，**直接跳 Phase 7，不要趕**。

### Phase 7：收尾提煉（110–120 min）

請學生複述一句話心法：

```text
「API 交給 Agent，我的工作是講清楚需求和驗算結果。」
```

- [] 回顧今天的三個收穫：工具鏈（中國可用）、驗算習慣、選圖心智模型。
- [] 預告下次：Seaborn 交互圖表，或拿 SocialPulse 的真實人脈數據畫她自己的圖。
- [] 課後作業（輕量）：用今天的方法，自己完成 customers.txt 的其中兩題，下次課前 5 分鐘驗收。

## 本堂絕對不要踩的坑

1. **不要除錯 Antigravity：** 區域限制是結構性的，今天零預算給它。
2. **不要一次裝多個 IDE：** 一個能跑就好，工具鏈不是集郵。
3. **不要代學生描述需求：** 第一題示範後，話必須她自己說，這是今天的核心訓練。
4. **不要跳過驗算：** 每一題都要抽查對數字，這是整堂課的靈魂，不可為了趕時間省略。
5. **不要預先避開中文亂碼坑：** 讓她親眼看到方框再修，記憶最深刻。
6. **不要講統計理論：** `std`、`percentile` 用到時讓 Agent 解釋，導師不展開。
7. **不要教 Python 基礎語法：** Jupyter 只是執行代碼的地方，不講迴圈不講型別。
