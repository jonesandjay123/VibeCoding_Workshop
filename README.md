最新の教材は [`session13/`](./session13/) にあります。「Jupyter と Pandas がよく分からない」という声を出発点に、15分間の学生デモ、kernel の状態実験、Pandas の6操作（読む・見る・選ぶ・絞る・集計・描く）を学びます。120分に休憩・予備時間・手計算・再起動後の全セル実行を含め、実行用 notebook、合成データの説明、講師用解答を用意しました。Codex を優先し、利用可能な既存ツールやローカル notebook を予備手段とします。学生自身が結果を予測し、条件を変更し、検証して図を作ります。
