最新教材在 `session10/`。本堂先用短時間驗證 Antigravity 與中國境內可用的 Agentic IDE，再把主要時間投入一個真實的人脈維護 Web App：由任何外部 LLM 將自然語言整理成固定 payload，App 負責驗證、預覽、人工修正與本機保存，不內建或綁定特定 LLM API。
