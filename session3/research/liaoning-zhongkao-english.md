# 遼寧省中考英語課綱研究

> 研究日期：2026-02-27
> 資料來源：遼寧省教育廳、維基百科、搜狐教育、無憂考網、教習網

---

## 📋 基本概況

### 考試名稱
**遼寧省初中學業水平考試**（簡稱「中考」）

### 重大改革
- **2024 年起**：遼寧省中考由各市自行命題改為**全省統一命題**
- **已取消考試大綱**：從 2024 年開始，遼寧中考逐步取消考試大綱，改以《義務教育課程標準（2022 年版）》為唯一命題依據
- 考生應關注《課程標準》中的學業質量要求，而非傳統的「考試大綱」

## 📖 英語科目詳情

### 分值與時間
| 項目 | 內容 |
|------|------|
| **總分** | **100 分** |
| **考試時間** | 筆試約 90 分鐘（含聽力） |
| **考試形式** | 閉卷筆試 |

### 題型結構（基於近年趨勢）
| 題型 | 說明 |
|------|------|
| **聽力** | 情景對話、短文理解 |
| **單選/語法填空** | 語法知識運用 |
| **完形填空** | 篇章理解 + 詞彙運用 |
| **閱讀理解** | 多篇閱讀（科技、環保主題增多） |
| **任務型閱讀** | 資訊提取、表格填寫 |
| **書面表達** | 應用文 + 觀點表達（可能結合圖表） |

### 命題趨勢（2025-2026）
1. **核心素養導向** — 注重跨學科綜合能力
2. **題型變化** — 寫作可能要求結合圖表或短篇閱讀提煉觀點
3. **主題傾向** — 科技、環保、人工智能、碳中和等社會熱點
4. **減少死記硬背** — 增加開放性、探究型題目

## 📚 課程標準要求（新課標 2022 版）

### 詞彙量要求
| 級別 | 詞彙量 | 對應年級 |
|------|--------|----------|
| 一級 | ~300-400 詞 | 小學 3-4 年級 |
| 二級 | ~600-700 詞 | 小學 5-6 年級 |
| **三級** | **~1500-1600 詞** | **初中畢業（中考要求）** |

> 新課標要求初中畢業生掌握約 **1500-1600 個基礎詞彙**，能理解和運用 **200 左右的習慣用語和固定搭配**。

### 語法要求（初中階段）
| 類別 | 具體內容 |
|------|----------|
| **時態** | 一般現在時、一般過去時、一般將來時、現在進行時、過去進行時、現在完成時 |
| **被動語態** | 一般現在時被動、一般過去時被動 |
| **句型** | 陳述句、疑問句、祈使句、感嘆句 |
| **從句** | 賓語從句、定語從句（基礎）、狀語從句（時間/條件/原因） |
| **非謂語** | 動詞不定式（基礎用法） |
| **其他** | 比較級/最高級、There be 句型、情態動詞 |

### 話題範圍（24 大主題）
1. 個人情況（Personal information）
2. 家庭、朋友和周圍的人（Family, friends and people around）
3. 周圍的環境（Personal environments）
4. 日常活動（Daily routines）
5. 學校生活（School life）
6. 興趣與愛好（Interests and hobbies）
7. 個人感情（Emotions）
8. 人際關係（Interpersonal relationships）
9. 計劃與願望（Plans and intentions）
10. 節假日活動（Festivals, holidays and celebrations）
11. 購物（Shopping）
12. 飲食（Food and drink）
13. 健康（Health）
14. 天氣（Weather）
15. 文娛與體育（Entertainment and sports）
16. 旅遊和交通（Travel and transport）
17. 語言學習（Language learning）
18. 自然（Nature）
19. 世界與環境（The world and the environment）
20. 科普知識與現代技術（Popular science and modern technology）
21. 熱點話題（Topical issues）
22. 歷史與地理（History and geography）
23. 社會（Society）
24. 文學與藝術（Literature and art）

## 📊 遼寧中考全科分值一覽

| 科目 | 分值 |
|------|------|
| 語文 | 120 分 |
| 數學 | 120 分 |
| **英語** | **100 分** |
| 物理 | 80 分 |
| 化學 | 50 分 |
| 道德與法治 | 70 分 |
| 歷史 | 70 分 |
| 體育與健康 | 60 分 |
| **合計** | **約 670 分** |

> 注：具體分值以遼寧省教育廳當年發布的《中考實施方案》為準

### 考試時間
- 筆試第一天：語文、數學
- 筆試第二天：物理與化學、英語
- 筆試第三天：歷史和道德與法治、地理與生物學

## 🔑 對「英語學習打卡」App 的啟示

### 核心需求
1. **1500 詞彙覆蓋** — 必須涵蓋新課標三級詞彙表
2. **情景對話練習** — 聽力佔分重要
3. **閱讀理解訓練** — 科技/環保主題為趨勢
4. **寫作模板** — 應用文 + 觀點表達

### 適合 App 功能設計
| 功能 | 對應中考需求 |
|------|-------------|
| 每日單詞打卡 | 1500 核心詞彙 |
| 語法小測驗 | 6 大時態 + 從句 |
| 閱讀理解練習 | 多主題短文 |
| 寫作範文庫 | 應用文模板 |
| AI 批改作文 | 語法糾錯 + 建議 |
| 聽力訓練 | 情景對話音頻 |
| 錯題本 | 個人化複習 |
