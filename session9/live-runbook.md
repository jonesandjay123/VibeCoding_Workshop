# Session 9 Live Runbook

> 目標：在不滿三小時的 Zoom 裡，讓學生實際參與對話與選擇；任何一個帳號、生成或網路環節失敗，課都能繼續。

## 推薦節奏：165 分鐘

| 時間 | 段落 | 目標 |
| --- | --- | --- |
| 0:00–0:10 | 開場與選題 | 說清楚今天不寫 code；從三個題目選一個。 |
| 0:10–0:35 | GPT Voice Live 圓桌 | 體驗能追問、插話的 AI 對談。 |
| 0:35–0:50 | 對話回看 | 一起挑出三句有價值的話、兩個還沒決定的問題。 |
| 0:50–1:10 | Spark Distiller demo | 看對話如何變成結論、假設、sparks 與下一步。 |
| 1:10–1:20 | 休息 | 同時讓 live distillation 繼續跑；不依賴其完成。 |
| 1:20–1:55 | 視覺生成選配 | 從一個 spark 產生 2–3 張圖，或做一支短片。 |
| 1:55–2:20 | AI 能力地圖 | 用剛才的體驗分辨：聊天、agent、圖像、影片、記憶／蒸餾各在做什麼。 |
| 2:20–2:40 | 人的驗收 | 找出輸出裡不對、太普通或不該交給 AI 的地方。 |
| 2:40–2:45 | 收尾 | 她選一條真正想帶走的結論或下一個小實驗。 |

## 開場講法

```text
今天不需要寫網站，也不需要背新的程式語言。

我們想試一件現在 AI 才開始做得比較像樣的事：
人可以直接跟 AI 開會、隨時改口；而且開完會以後，
AI 可以幫我們把真正有價值的想法整理留下來。

但今天每一個方向還是由妳選。AI 是同事，不是替妳決定的人。
```

## Voice Live 前的檢查

- [ ] 普通 ChatGPT 網頁版或手機 app 已登入（不是 Codex）。
- [ ] Settings → Voice 可選到 `Live`。
- [ ] 麥克風權限已開；最好使用耳機，避免 Zoom 回音。
- [ ] 準備文字版 prompt；若 Live 不可用，直接用一般文字 ChatGPT 進行同樣的提問。
- [ ] 不分享私人資料、帳密、私人社群或未同意的第三方內容。

## Spark Distiller 前的檢查

- [ ] 已用自己的 allowlisted Cloudflare Access 帳號登入 public UI。
- [ ] 有一份 5–8 分鐘、去識別化、已 ready 的範例 session。
- [ ] 如要 live 跑，transcript 不超過一頁，且已去除私人資訊。
- [ ] 不將學生真實 Zoom 全錄或完整聊天紀錄直接丟入；只擷取雙方同意的短摘要。
- [ ] ready 結果可展示：`今天的結論`、`改變的想法`、`待驗證問題`、`下一個小實驗`。

## 視覺生成前的檢查（只有選 A 才需要）

- [ ] 先確認 Google Flow 或 Adobe Firefly 帳號、地區、credits。
- [ ] 準備一張虛構或可公開使用的參考圖；可用 DouceReverie hero，不用真人私照。
- [ ] 有一張已產好的成功範例與一張失敗範例，避免等待生成造成冷場。
- [ ] 只生成 8–15 秒、單一鏡頭的短片；不追求現場剪出完整作品。

## 三種分流

### Route A：Voice、Distiller、視覺工具都順

依表走完整流程。視覺段只做一個 spark，不做多個主題。

### Route B：Voice 可用，但 Spark Distiller live 等待中

展示預先 ready 的範例；讓學生先猜「這段對話真正的結論是什麼」。等候期間做視覺段或 AI 真偽／品質批評。

### Route C：Voice 或所有生成工具不可用

直接用一般文字 ChatGPT 扮演訪談主持人，再展示 Spark Distiller 的 ready 範例。課程重點仍是：對話 → 整理 → 人的選擇。

## 不要踩的坑

- 不把 GPT Voice 當成神奇客服；它可追問，但仍會誤解或講得太滿。
- 不在 Zoom 內同時外放 Voice 音訊與麥克風，容易回音；用耳機或關閉不必要的收音。
- 不臨場用影片生成測太複雜的角色、多場景、長劇情。
- 不因為 Distiller 的 live job 還未 ready 而停在 loading 畫面等待。
- 不以「這個結果漂亮」當作唯一驗收；必問它是否符合原本想法、是否有錯誤或不可信之處。

## 收尾問題

```text
剛才哪一段比較像真的在和同事討論？
AI 幫我們留下了什麼，卻沒有辦法替我們判斷什麼？
哪個結果看起來厲害、但其實妳不會採用？
如果下次只有妳和 AI，妳會先請它幫妳做哪一件小事？
```
